# Legacy font encoding data

`symbol.py` and `zapfding.py` contain the encoding tables from pypdf 6.15.0,
`pypdf/_codecs/`, for the compatibility facades. Upstream source:
https://github.com/py-pdf/pypdf/tree/6.15.0/pypdf/_codecs

The tables derive from Unicode Consortium Adobe Symbol and Zapf Dingbats
mappings. Their original notices remain in each file. The pypdf BSD-3-Clause
license is retained in `LICENSE`. Mapping values and notices are unchanged;
Python formatting follows this repository. No pypdf implementation or dependency
is used.
